# Linux Systems Labs

Hands-on Linux labs documenting my progress from foundational commands toward systems, networking, automation, and DevOps.

Each lab is added only after I run it and provide working evidence. This repository separates practical work from topics I have only watched or studied.

## Environment

- Ubuntu 24.04.1 LTS
- Windows Subsystem for Linux 2 (WSL2)
- Bash shell

## Labs

### Day 1 — Linux and Client-Server Foundations

I practised:

- identifying the current user, directory, kernel, architecture, and operating system;
- creating directories and files;
- distinguishing the parent directory from the previous working directory;
- running a local Python HTTP server;
- requesting a file with `curl` and interpreting `200 OK`.

See [Day 1: Foundations](day-01-foundations/README.md).

## Evidence standard

Every completed lab should include:

1. the commands I ran;
2. sanitized output showing the result;
3. a short explanation of what the result means;
4. troubleshooting notes when something goes wrong.

Machine names, public IP addresses, credentials, tokens, and unrelated home-directory listings are excluded from published evidence.
